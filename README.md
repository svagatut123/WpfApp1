# Стриминговая платформа аудио- и видеоконтента (УП.01.01)

## Описание проекта
Десктопное приложение на базе **WPF (.NET Framework)** с использованием архитектуры MVVM/Page-навигации и Entity Framework. Предназначено для управления каталогом медиаконтента (фильмы, музыка, подкасты) с разграничением прав доступа для ролей «Администратор» и «Пользователь».

## Структура репозитория
- `README.md` — описание проекта и структуры решения.
- `db/schema.sql` — скрипт создания структуры базы данных и таблиц (`Roles`, `Users`, `Content`).
- `res/` — каталог ресурсов приложения (включает логотип `Логотип.png` и иконки).

## Основной функционал
1. **Авторизация и безопасность:**
   - Авторизация пользователей с привязкой к ролям.
   - Защита от брутфорса: генерация и проверка капчи после 3 неудачных попыток входа.
   - Безопасное хранение паролей и управление учетными записями (смена пароля).
2. **Панель Администратора:**
   - Полноценный CRUD (создание, чтение, обновление, удаление) записей каталога.
   - Поиск, сортировка и фильтрация контента.
   - Экспорт отчетов в форматы `.xlsx` (через CSV), `.docx` (HTML-формат) и текстовые отчеты.
   - Графическая аналитика распределения контента по типам.
3. **Панель Пользователя:**
   - Просмотр каталога медиаконтента.
   - Удобная фильтрация и поиск.
4. **Дополнительные возможности:**
   - Единый словарь стилей и фирменная цветовая палитра на базе шрифта Open Sans.
   - Динамическое переключение светлой и темной тем оформления с сохранением состояния.
   - Проверки формата ввода данных, маски и подтверждение критических действий.
